## Înainte de publicare
1. Înlocuiește `EXEMPLU-DOMENIU.ro` în `index.html` și `sitemap.xml` cu domeniul real.
2. Adaugă fotografii reale ale lucrărilor.
3. Verifică datele firmei și textul comercial.
4. Publică pe GitHub Pages sau alt hosting static.
5. Adaugă domeniul în Google Search Console și trimite `sitemap.xml`.

Site-ul nu garantează o poziție anume în Google; indexarea și clasarea depind de Google și de calitatea/conținutul site-ului.
